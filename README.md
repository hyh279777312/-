# 🚀 火枪手剪映工程迁移工具 (HQS Jianying Packager) V4.3.2

> 专业、高效、智能的剪映 Mac/Windows 本地工程一键打包与跨设备回批迁移工具。

---

## 📌 软件介绍

在剪辑工作中，将剪映工程（Draft）迁移至其他电脑时，往往面临素材分散、文件体积庞大、路径失效等痛点。**火枪手剪映工程迁移工具** 专为剪辑师与工作室打造，集成了**本地打包 V4.3.2 增强引擎**与**智能回批 V1.7 稳定核心**，完美解决剪映工程跨设备迁移的所有难题。

---

## ✨ 核心能力与优势

1. **精准时间线过滤（拒绝冗余）**：
   - 深度解析剪映时间线 JSON（支持加密草稿原生解密），**只复制时间线上实际引用的本地素材与音频**，大幅压缩打包体积。
2. **容量与时间双重实时监控**：
   - 实时读取并显示草稿工程总容量（如 `72.7G`）及已打包/已回批容量。
   - 提供精准的已耗时与预估剩余时间统计（`MM:SS`），让迁移进度尽在掌握。
3. **安全不修改原工程**：
   - 所有解密、过滤与组合均在临时独立目录中进行，绝不破坏或修改您的原始工程。
4. **智能回批与路径重定向**：
   - 跨设备迁移后一键智能回批，自动重构绝对路径映射，一键安装至新电脑剪映默认草稿箱。
5. **双平台深度适配**：
   - 完美支持 macOS（M 系列与 Intel）及 Windows 系统，提供直观的现代化图形界面与一键脚本。

## 📦 安装与使用说明

### 📥 软件下载与安装
- **macOS 用户**：下载 `.dmg` 安装包或直接运行 `一键打包App和DMG.command`。
- **Windows 用户**：下载便携版 `.exe` 或运行 `一键打包Windows版.bat`。

### 🛠️ 使用步骤指南

#### 步骤一：本地打包（源电脑）
1. 打开应用，进入 **【本地打包 V4.3.2】** 标签页。
2. 点击 **【选择工程】** 按钮，选中您的剪映 Mac/Win 草稿工程文件夹（如 `com.lveditor.draft/YOUR_PROJECT`）。
3. （可选）点击 **【指定输出】** 选择打包后的存放路径（默认在工程同级目录）。
4. 点击 **【开始打包】**，系统将自动解密、过滤并复制所需素材，实时显示容量与打包进度。

#### 步骤二：智能回批（目标新电脑）
1. 将打包好的整个文件夹通过移动硬盘或网盘传输到新电脑。
2. 打开应用，切换至 **【智能回批 V1.7】** 标签页。
3. 点击 **【选择打包目录】**，选中传输过来的打包文件夹。
4. 点击 **【开始智能回批】**，系统将自动重建素材绝对路径，并安全安装到新剪映草稿目录中。
